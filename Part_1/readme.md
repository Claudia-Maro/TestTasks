# Обработка списка чисел

Этот скрипт принимает от пользователя список целых чисел, разделенных запятыми, и выполняет с ними несколько операций.

## Функциональность

1. **Ввод данных**:
   - Запрашивает у пользователя строку с числами, разделенными запятыми
   - Удаляет лишние пробелы вокруг чисел
   - Пропускает пустые элементы

2. **Валидация**:
   - Проверяет, что введены данные
   - Преобразует строки в целые числа
   - Пропускает нечисловые значения с выводом предупреждения

3. **Обработка чисел**:
   - Находит максимальное и минимальное число
   - Выводит все четные числа
   - Сортирует числа по возрастанию с помощью алгоритма сортировки вставками

## Использование

1. Запустите скрипт
2. Введите числа через запятую (например: `16, 14, 3, 19`)
3. Программа выведет:
   - Максимальное и минимальное число
   - Список четных чисел
   - Отсортированный список

## Обработка ошибок

- Если ввод пустой - программа завершится с сообщением
- Если нет корректных чисел - программа завершится с сообщением
- Некорректные значения пропускаются с предупреждением

## Алгоритмы

Используется сортировка вставками:
- Эффективна для небольших списков
